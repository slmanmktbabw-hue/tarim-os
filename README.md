# 🛡️ TARIM OS - المنصة السيادية العالمية

نظام تشغيل وإدارة عالمي متكامل يعتمد على خوادم Node.js وقاعدة بيانات SQLite حقيقية وثابتة، مع دعم تثبيت التطبيق بشكل كامل كـ PWA من المتصفح والاتصال العالمي بجميع الدول.

## 🚀 الميزات والتشغيل المؤكد
* **التثبيت المباشر (PWA):** يعمل كبرنامج مستقل بذاته على الشاشة الرئيسية للهاتف عبر المتصفح والدومين.
* **الأزرار الخمسة (مؤكدة التشغيل 100%):**
  1. **الرئيسية (1):** إدارة الخلاصة، البث العام، فريق الدعم، المجتمع، وعين الذكاء الاصطناعي.
  2. **العمليات (2):** المراسلة والاتصال الآمن، خريطة حضرموت وتريم (Offline)، وإصدار الختم الميداني المشفر + QR.
  3. **الإنشاء (+ / 3):** لوحة مركزية لصورة إلى نص (OCR)، منشورات، LIVE (بث مباشر مستقر على 8 دقائق)، وفلاتر تجميلي.
  4. **صندوق الوارد (4):** المراسلة الفورية والآمنة بين المستخدمين عبر السوكت (Socket.io).
  5. **الملف الشخصي والإعدادات (5):** إدارة الرصيد، مركز الأنشطة، فيديوهات أوفلاين، رمز QR لديك، المجموعة التجارية، الترويج، والإعدادات والخصوصية الشاملة.

# 🛡️ TARIM OS v12.1 - القلعة السيادية

نظام تشغيل وإدارة متكامل يعتمد على خوادم **Node.js** وقاعدة بيانات **SQLite** حقيقية وثابتة، مع دعم تثبيت التطبيق بشكل كامل كـ **PWA** من المتصفح.

---

## 🚀 المميزات والتشغيل المؤكد

* **التثبيت المباشر (PWA):** يعمل كبرنامج مستقل بذاته على الشاشة الرئيسية للهاتف عبر المتصفح.
* **الأزرار الخمسة (مؤكدة التشغيل 100%):**
  1. **الرئيسية:** إدارة الخلاصة والبث العام والتنبيهات.
  2. **العمليات:** بث مباشر مشفر (8 دقائق)، مراسلة آمنة، خريطة حضرموت وتريم (Offline)، وإصدار الختم الميداني + QR.
  3. **الإنشاء (+):** لوحة مركزية لصورة إلى نص، المنشورات، البث المباشر (LIVE)، والفلاتر البصرية.
  4. **صندوق الوارد:** المراسلة الفورية والآمنة بين المستخدمين عبر السوكت (Socket.io).
  5. **الملف الشخصي والإعدادات:** إدارة الرصيد، رمز QR، الإعدادات والخصوصية الشاملة (إدارة المنشورات، تفضيلات المحتوى، الأمان والاذونات، والتحليلات).

---

## 🔒 الحماية السيادية وتأمين الثغرات

* **تشفير كلمات المرور:** استخدام مكتبة `bcrypt` لتشفير بيانات الاعتماد وحمايتها من الاختراق أو التسريب.
* **عزل طبقات العرض:** ضبط مؤشرات التفاعل (`z-index` و `pointer-events`) لمنع أي تداخل بصري أو تعطل للأزرار السفلية.
* **حماية قاعدة البيانات:** اعتماد معاملات آمنة في `SQLite` لمنع ثغرات الحقن (SQL Injection).

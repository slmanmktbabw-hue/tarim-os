
# TARIM OS - النظام السيادي العالمي (tarimos.org) 🏰

منصة تواصل وعمليات سيادية حقيقية مخصصة لربط حضرموت والعالم، مربوطة بمحفظة OKX الملكية الخاصة بالملك AL:
## 🚀 خطوات النشر والتشغيل الشامل:
1. **استضافة الخادم (Backend):** - ارفع الملفات إلى مستودع GitHub خاص بك.
   - اربط المستودع بمنصة استضافة سحابية مثل **Render** أو **Railway**.
   - اجعل أمر بدء التشغيل (Start Command): `npm start`.
2. **ربط الدومين:**
   - اربط نطاقك المخصص **tarimos.org** بمنصة الاستضافة السحابية عبر سجلات الـ DNS (CNAME / A Records).
3. **التثبيت على الجوال:**
   - افتح المتصفح على هاتفك وقم بزيارة `https://tarimos.org`.
   - سيظهر لك زر "تثبيت التطبيق" أو من خيارات المتصفح اختر **"إضافة إلى الشاشة الرئيسية"** ليظهر التطبيق كأيقونة مستقلة وثابتة على هاتفك تماماً كما في صورك الشخصية.
